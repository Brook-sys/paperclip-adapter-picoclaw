# Contributing to paperclip-adapter-picoclaw

First off, thank you for considering contributing! 🎉 

This project was born out of a real need to connect two awesome tools (Paperclip and PicoClaw). We want to keep it simple, open, and community-driven. 

Whether it's fixing a typo, adding a new feature, reporting a bug, or just improving the documentation, **all contributions are welcome!**

*Leia isto em [Português](CONTRIBUTING.pt-BR.md)*

## How can you help?

### 🐛 Did you find a bug?
Don't keep it to yourself! Open an [Issue](https://github.com/Brook-sys/paperclip-adapter-picoclaw/issues) and let us know. Include:
- A quick summary of the bug.
- Steps to reproduce it.
- Logs or terminal output if applicable.

### ✨ Have an idea for a new feature?
Awesome! We love new ideas.
1. Open an [Issue](https://github.com/Brook-sys/paperclip-adapter-picoclaw/issues) describing your feature so we can discuss it.
2. If you already know how to build it, feel free to submit a Pull Request directly!

### 💻 Want to write some code?
1. **Fork** the repository.
2. **Clone** it locally: `git clone https://github.com/your-username/paperclip-adapter-picoclaw.git`
3. Create a branch for your feature: `git checkout -b my-awesome-feature`
4. Make your changes in the `package/` folder.
5. Make sure everything is working.
6. Commit your changes: `git commit -m "feat: adding awesome feature"`
7. Push to your fork: `git push origin my-awesome-feature`
8. Open a **Pull Request** targeting the `main` branch.

## Development Setup

The adapter code lives inside the `package/` directory. 
- Source files are standard ES Modules.
- Edit the files in `package/dist/server/` or `package/dist/ui/`.
- You can use `npm link` to test the adapter locally with your own Paperclip instance before committing.

## You are welcome here

There are no silly questions or small contributions. If you want to help but don't know where to start, open an issue saying "I want to help!" and we'll figure it out together.

Happy coding! 🚀
