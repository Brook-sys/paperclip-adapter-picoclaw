# Contribuindo para paperclip-adapter-picoclaw

Antes de mais nada, muito obrigado pelo seu interesse em contribuir! 🎉

Este projeto nasceu de uma necessidade real de conectar duas ferramentas incríveis (Paperclip e PicoClaw). Queremos manter o projeto simples, aberto e movido pela comunidade.

Seja corrigindo um erro de digitação, adicionando uma nova funcionalidade, relatando um bug ou apenas melhorando a documentação, **todas as contribuições são bem-vindas!**

*Read this in [English](CONTRIBUTING.md)*

## Como você pode ajudar?

### 🐛 Encontrou um bug?
Não guarde para você! Abra uma [Issue](https://github.com/Brook-sys/paperclip-adapter-picoclaw/issues) e nos conte. Inclua:
- Um resumo rápido do problema.
- Passos para reproduzi-lo.
- Logs ou saídas do terminal, se tiver.

### ✨ Tem uma ideia para uma nova funcionalidade?
Incrível! Nós adoramos novas ideias.
1. Abra uma [Issue](https://github.com/Brook-sys/paperclip-adapter-picoclaw/issues) descrevendo sua funcionalidade para podermos conversar sobre ela.
2. Se você já sabe como codar a solução, fique à vontade para abrir um Pull Request diretamente!

### 💻 Quer escrever código?
1. Faça um **Fork** do repositório.
2. Faça o **Clone** localmente: `git clone https://github.com/seu-usuario/paperclip-adapter-picoclaw.git`
3. Crie uma branch para a sua funcionalidade: `git checkout -b minha-feature-incrivel`
4. Faça suas alterações dentro da pasta `package/`.
5. Garanta que tudo está funcionando.
6. Faça o commit das suas alterações: `git commit -m "feat: adicionando feature incrivel"`
7. Envie para o seu fork: `git push origin minha-feature-incrivel`
8. Abra um **Pull Request** apontando para a branch `main`.

## Configuração de Desenvolvimento

O código do adaptador vive dentro do diretório `package/`.
- Os arquivos-fonte são Módulos ES (ESM).
- Edite os arquivos em `package/dist/server/` ou `package/dist/ui/`.
- Você pode usar `npm link` para testar o adaptador localmente com a sua própria instância do Paperclip antes de enviar o commit.

## Você é bem-vindo(a) aqui

Não existem perguntas bobas ou contribuições pequenas. Se você quer ajudar mas não sabe por onde começar, abra uma Issue dizendo "Quero ajudar!" e nós descobrimos juntos.

Bom código! 🚀
