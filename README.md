# Paperclip Adapter for PicoClaw

An external adapter plugin for [Paperclip](https://paperclip.ing) that enables execution of LLM agents via [PicoClaw](https://github.com/sipeed/picoclaw). 

This adapter acts as a bridge: Paperclip handles orchestration (control plane, issues, skills), while PicoClaw acts as the remote execution engine, running the model, prompt, and local tools (shell, filesystem) via the Pico WebSocket Protocol.

*Leia isto em [Português](README.pt-BR.md)*

## Prerequisites

1. **Paperclip** running (v2026.414+ with npm plugin support).
2. **PicoClaw Gateway** running and accessible over your network.
3. **Node.js** installed on the PicoClaw host machine (highly recommended for native Paperclip MCP tool support).

## How It Works

When a Paperclip heartbeat triggers, this adapter sends the contextual prompt and injected skills to PicoClaw. The LLM operating inside PicoClaw performs the work locally in its environment. It communicates back with Paperclip (to check out issues, post comments, etc.) either by using native MCP tools or by falling back to `curl` commands generated by the adapter's built-in playbook.

## Setup & Configuration

### 1. PicoClaw Gateway Configuration (Crucial)

For the best experience, you must install the Paperclip MCP server inside your PicoClaw environment so the LLM can natively interact with the Paperclip Control Plane.

In your PicoClaw configuration (e.g., your tools or MCP JSON file), register the official Paperclip MCP Server:

```json
"servers": {
  "paperclip": {
    "enabled": true,
    "command": "npx",
    "args": [
      "-y",
      "@paperclipai/mcp-server"
    ],
    "type": "stdio",
    "env": {
      "PAPERCLIP_API_URL": "http://<YOUR_PAPERCLIP_IP>:3100",
      "PAPERCLIP_API_KEY": "pcp_your_agent_or_company_token_here",
      "PAPERCLIP_COMPANY_ID": "<YOUR_COMPANY_UUID>"
    }
  }
}
```

*Note: The `PAPERCLIP_API_URL` must point to the raw API port (usually `:3100`), not an external proxy that serves the HTML UI.*

### 2. Paperclip Installation

Install the adapter in your Paperclip environment:
```bash
npm install paperclip-adapter-picoclaw
```

Add the plugin to your `paperclip.json` configuration:
```json
{
  "adapters": {
    "picoclaw": "paperclip-adapter-picoclaw"
  }
}
```

### 3. Agent UI Configuration

Inside the Paperclip Web UI, create or edit an Agent and select the `picoclaw` adapter. You will need to provide:

- **PicoClaw Gateway URL:** The WebSocket endpoint (e.g., `ws://10.0.0.5:18790/pico`).
- **Authentication Token:** The token matching your PicoClaw `channels.pico.token` config.
- **Run Timeout & Grace Period:** Ensure the timeout is long enough to handle complex PicoClaw operations.

## Known Limitations

- **Dynamic Model Selection:** The Pico WebSocket Protocol does not currently accept dynamic model override parameters from the client. The LLM model is entirely defined by the PicoClaw server's backend YAML configuration (`agents.defaults.model_name`), not the Paperclip UI.
- **Tool Fallbacks:** If the MCP server is not configured in PicoClaw, the adapter forces the LLM to use `curl` via bash to interact with Paperclip. While functional, it is much slower and error-prone. We strongly recommend the MCP setup.

## Troubleshooting

- **Error: `tool not found: paperclip`**  
  The LLM tried to use Paperclip's native tools, but the MCP server is not registered or failed to start in PicoClaw. See the setup instructions.
- **Agent receives HTML instead of JSON from API**  
  Your `PAPERCLIP_API_URL` is pointing to a frontend UI/Proxy router instead of the raw Backend API. Ensure it points directly to port `3100` and does not include a trailing slash.
- **Error: `Input token count exceeds...`**  
  The LLM entered a loop or read too many large files. Clear the PicoClaw memory/workspace or assign a model with a larger context window on the PicoClaw server.
